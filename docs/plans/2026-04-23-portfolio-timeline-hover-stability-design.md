# Portfolio Timeline Hover Stability Design

**目标**

修正首页时间轴在鼠标经过时的跳动感，同时补齐两处时间文案，并让“个人 AI 项目”节点点击后直接进入项目页。

**问题判断**

当前时间轴的详情卡虽然已经改成浮层，但它会随着不同节点横向移动。用户在多个节点之间扫读时，详情卡位置持续变化，会形成明显的视觉位移，因此主观感受仍然是“在跳”。

**设计决策**

本轮采用固定详情卡位置的方案：

1. 详情卡始终固定在时间轴上方中部。
2. `hover` 或聚焦节点时，只切换详情卡内容，不再切换详情卡位置。
3. 详情卡继续使用渐显渐隐，保留柔和感。
4. 节点仍保留轻微高亮，用来表达当前焦点，但不再引入布局位移。

**数据调整**

1. `复旦大学新闻与传播硕士` 的索引时间改为 `2024-2026`。
2. `个人 AI 项目` 的索引时间改为 `2025-2026`。
3. `个人 AI 项目` 节点增加项目页跳转配置，点击后直接进入站内作品页。

**实现约束**

1. 只修改首页时间轴相关数据、组件、样式与测试。
2. 保持 hover 预览能力不变。
3. 不扩展新的首页结构调整。
