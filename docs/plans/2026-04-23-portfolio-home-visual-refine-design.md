# Portfolio Home Visual Refine Design

**目标**

将个人站首页重构为真正的一屏式封面：用户第一次进入时，无需点击、无需下拉，即可直接看到两行简介、右上人物主视觉、真正的横向直线时间轴、个人 AI 项目与底部联系方式。

**设计方向**

本轮采用“高级编辑感”的视觉路线，整体参考高质量作品集和杂志扉页的阅读秩序，而不是产品后台或功能导航页。页面要让招聘方第一眼感受到三个判断：

1. 这是一个有审美控制力的人做出来的页面。
2. 这个人有清晰的成长主线，而不是散乱堆经历。
3. 她的 AI 项目是基于真实需求做出来的，而不是概念展示。

**必须满足的首屏信息结构**

1. 左上区域：姓名与两行简介。
2. 右上区域：英文 tab + 正式照片主视觉。
3. 中段主体：横向直线时间轴，必须由一条连续细线和多个时间点构成。
4. 下段区域：左侧个人 AI 项目精选卡片，右侧联系方式。

**明确删除项**

1. 首页不再展示三个导航入口卡片。
2. 首页不再要求用户点击后才看到核心信息。
3. 首页时间轴不再使用“单个卡片并排摆放”的伪时间轴形式。
4. 联系方式不再出现在页面上半部分。
5. 首页不再出现大面积无效留白。

**版式设计**

页面维持单屏阅读逻辑，但版面分成三层：

1. 顶层信息带：左侧品牌介绍，右侧人物主视觉，人物区域顶部放英文 tab。
2. 中层主视觉：横向时间轴贯穿整行，是整页最强的结构元素。
3. 底层证据区：左侧个人 AI 项目卡片，右侧联系方式。

其中，时间轴必须是页面视觉中心，其他模块要围绕它让位，避免再次回到“卡片很多、主次不明”的状态。

**字体层级**

1. 姓名使用更有展示感的衬线标题字体，强化识别度。
2. 两行简介保持较大字号，但行长严格受控，避免散。
3. 时间轴年份使用更克制的小号大写/数字节奏，经历标题保持短促有力。
4. 英文 tab 必须简洁、克制，不抢姓名与照片的主视觉关系。
5. 联系方式与辅助说明统一弱化处理，作为底部支持信息。

**卡片与边框语言**

1. 卡片从“产品组件感”调整为“版芯块面感”。
2. 使用更轻的边框、更小的圆角、更少的阴影。
3. 减少大面积按钮感与强交互感，改为更像印刷版面上的信息块。

**横向时间轴规范**

1. 采用一条连续的细直线横向贯穿。
2. 每个经历节点由“时间点圆形标记 + 年份 + 经历标题 + 简短说明”构成。
3. 文本上下交错排布，避免所有说明都堆在同一侧导致呆板。
4. 时间点视觉统一，但当前阶段节点可以用更深的点或更强的描边突出。
5. 必须补上“复旦大学新闻与传播硕士”这一学历节点，保证成长主线完整。

**个人 AI 项目区规范**

首页只展示一个代表性个人 AI 项目，优先突出“新传 Mind”或“个人 AI 项目主线”的综合表达。内容结构固定为：

1. 项目标题
2. 一句项目定位
3. 三条能力证据
4. 一个低干扰的跳转动作

**联系方式规范**

联系方式保留：

1. 简历 PDF
2. GitHub
3. 手机号
4. 邮箱

展示形式应更像个人名片信息，不要再使用四个均质按钮块，并且放在首页最下方。

**照片使用规范**

1. 使用 `白底正式风.png` 作为首页右上主视觉。
2. 照片以“正式个人品牌照”方式呈现，不做圆形头像处理。
3. 通过裁切比例、边框与留白让照片和版面风格一致，避免像简历附件。

**实现约束**

1. 保持现有 React 路由结构不变。
2. 优先复用现有数据源 `client/src/data/portfolio/content.js`，只做必要的结构补充。
3. 测试先行，先更新首页行为测试，再改组件和样式。
4. 不改动详情页路由，仅精修首页。
